# Machine Learning: Foundations and Practice

**[Open the presentation in your browser](https://clmntgq.github.io/Machine-Learning-foundation-and-practice/machine-learning.html)**

A hands-on introduction to machine learning for engineering students. Start by framing a problem and preparing data, then train, compare, and evaluate models on examples such as Titanic survival and California housing prices.

## What you’ll learn

- Prepare and split data, build preprocessing pipelines, and avoid data leakage.
- Train linear models, trees and ensembles, nearest-neighbour models, SVMs, and introductory neural networks.
- Choose metrics and validation strategies, then explore clustering, PCA, anomaly detection, and transfer learning.
- Assess robustness, explainability, and fairness, and turn a notebook into a prediction pipeline.

The course combines explanations, guided Python exercises, and a team project. Basic Python, linear algebra, calculus, and probability are recommended.
